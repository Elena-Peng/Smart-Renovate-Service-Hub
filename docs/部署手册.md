# 筑见装修咨询服务智能平台 —— 云服务器部署手册

> 目标：把项目跑在一台公网服务器上，别人用 `http://服务器IP:8080` 就能访问（含业主端 / 服务商端 / 管理端）
> 成本：2核2G 约 ¥68 / 年（够用，脚本会自动降配），2核4G 约 ¥109–199 / 年（更宽松）
> 耗时：首次部署约 30 分钟
> 适用：阿里云 ECS / 腾讯云轻量，只要是 Ubuntu 22.04 且能拿到 root 就行

---

## 一、先把认知对齐：这是一个服务

项目的前端页面由 Spring Boot 自己托管（`StaticWebConfig` 里 `addResourceLocations("file:./web/")`），
所以**不需要买两台服务器**，也不需要 Nginx 单独托管前端。一台机器上跑：

```
轻量服务器（Ubuntu 22.04）
├─ JDK 17          ← 跑 jar
├─ MySQL 8         ← 存数据（flyway 自动建表）
└─ app.jar + web/  ← 后端 + 前端静态文件
```

---

## 二、购买与选型（阿里云 / 腾讯云都可以）

1. 产品要选**轻量应用服务器**或 **ECS**，不要选高配通用型
2. **镜像选择**：`Ubuntu 22.04 LTS`（本手册脚本按这个写的；不要选 CentOS 7，它的 MySQL 源已停止维护；也不要选宝塔等应用镜像）
3. 地域选离你近的（广州 / 深圳 / 杭州），后续答辩演示延迟低
4. 创建后记下：**公网 IP**、root 密码（在「实例详情 → 重置密码」可改）
5. 学生认证后价格更低（腾讯云「云+校园」、阿里云「飞天加速计划」都有学生机）

### 内存要多少：2核2G 可以跑

实测（本项目 jar 以 `-Xmx768m` 启动、访问 5 次后）：Java 进程工作集约 **383MB**、MySQL 约 **85–300MB**、系统约 150MB。
2G 机器配 `2G swap` + MySQL 轻量调参（`install-server.sh` 会自动做）可以稳定运行；
4G 机器则无需任何调优，压力测试时更从容。**预算够就上 4G，只想省钱 2G 也能跑。**

> ⚠️ 用 `IP:8080` 访问**不需要域名备案**；一旦绑定自己的域名，国内服务器必须先备案。

## 三、放行端口（最容易漏的一步）

云厂商默认只开 22（SSH），8080 必须自己放行：

- **腾讯云轻量**：控制台 → 实例 → **防火墙** → 添加规则：协议 `TCP`、端口 `8080`、来源 `0.0.0.0/0`、备注「筑见平台」
- **阿里云 ECS**：控制台 → 实例 → **安全组** → 入方向 → 手动添加：协议类型 `自定义TCP`、端口范围 `8080/8080`、授权对象 `0.0.0.0/0`

> 想以后换 80 端口访问，就再加一条 `TCP 80`。

> 不做这步，服务在本机能 curl 通，但外网打不开 —— 90% 的「部署失败」都是这里。

## 四、登录服务器

Windows 打开 Git Bash（你已装好），执行：

```bash
ssh root@<你的公网IP>
```

第一次连会提示 `Are you sure you want to continue connecting?`，输入 `yes` 回车，然后输密码（输入时不显示字符，属正常）。

## 五、上传程序文件（在你自己的电脑上执行，不是在服务器上）

### 5.1 先在本机打包最新 jar

在 IDEA 右侧 **Maven** 面板 → `Lifecycle → clean` → 再 `package`（跳过测试可加 `-DskipTests`）。
产物：`target/smart-renovate-service-hub-1.0.0.jar`

> 命令行打包（你本机的 Maven 在 `D:\env\apache-maven-3.9.16`；原来的 `D:\env\maven3.6.1` 版本是 3.6.1，低于插件要求的 3.6.3，会报 `requires Maven version 3.6.3`，不要用）：
> ```powershell
> cd "C:\Users\30279\Desktop\Smart Renovate Service Hub"
> D:\env\apache-maven-3.9.16\bin\mvn.cmd clean package -DskipTests
> ```

### 5.2 改个名字方便部署

把 jar 重命名为 `app.jar`（服务配置里固定读 `app.jar`）：

```powershell
copy "target\smart-renovate-service-hub-1.0.0.jar" "app.jar"
```

### 5.3 上传（Git Bash 里执行）

```bash
cd "/c/Users/30279/Desktop/Smart Renovate Service Hub"

# 上传脚本
scp deploy/install-server.sh root@<公网IP>:/root/

# 上传 jar（传之前先在服务器建目录，见第 6 步）
scp app.jar root@<公网IP>:/opt/zhujian/app.jar

# 上传前端静态文件（web 目录必须一起传，否则页面 404）
scp -r web root@<公网IP>:/opt/zhujian/
```

> 上传 52MB 的 jar 在国内带宽下约 1–3 分钟，卡住不动通常是网络抖动，重跑同一条命令即可（会覆盖）。

## 六、服务器上装环境 + 启动（服务器端执行）

```bash
# 1. 先建目录（脚本也会建，但上传前必须先存在）
mkdir -p /opt/zhujian

# 2. 一键装环境：JDK17 + MySQL8 + 建库建账号 + systemd 服务
bash /root/install-server.sh
```

脚本跑完会打印 3 条待办，照做即可：

```bash
# 3. 填 API Key（火山方舟的 key，公网仓库里不含它）
nano /etc/zhujian/zhujian.env
# 找到 ARK_API_KEY= 这一行，改成 ARK_API_KEY=ark-你的key
# Ctrl+O 回车保存，Ctrl+X 退出

# 4. 启动
systemctl start zhujian
systemctl status zhujian

# 5. 看日志（启动约 20–40 秒，看到 Started ZhujianApplication 就是成功）
tail -f /opt/zhujian/app.log
```

## 八、以后更新代码怎么发版

```bash
# 本机重新打包 → 上传 → 重启（三步）
D:\env\apache-maven-3.9.16\bin\mvn.cmd clean package -DskipTests
scp app.jar root@<公网IP>:/opt/zhujian/app.jar
ssh root@<公网IP> "systemctl restart zhujian && sleep 3 && systemctl status zhujian --no-pager"
```

前端页面改动（`web/` 下文件）不需要重启，重新 `scp -r web ...` 后浏览器 `Ctrl+F5` 强刷即可。

## 九、常见报错排查表

| 现象 | 原因 | 处理 |
|---|---|---|
| 浏览器打不开，本机 `curl 127.0.0.1:8080` 通 | 腾讯云防火墙没放行 8080 | 控制台「防火墙」加 `TCP 8080` 规则 |
| `systemctl status` 显示 `failed` | jar 没传、或路径不对 | `ls -l /opt/zhujian/app.jar`；`journalctl -u zhujian -n 50 --no-pager` |
| 日志 `Access denied for user 'zhujian'@'127.0.0.1'` | DB 密码不一致 | 打开 `/etc/zhujian/zhujian.env` 核对；或重跑 `install-server.sh`（会复用旧密码） |
| 日志 `Communications link failure` | MySQL 没启动 | `systemctl start mysql` → `systemctl enable mysql` |
| 日志 `Port 8080 was already in use` | 端口被占 | `ss -lntp \| grep 8080` 找到进程后 `kill`，或改 `zhujian.env` 的 `SERVER_PORT` |
| 页面 404 / 白屏 | `web/` 目录没上传，或不在 `/opt/zhujian/web` | `ls /opt/zhujian/web` 应看到 `index.html`、`app.js` |
| 登录后 AI 功能报错 | `ARK_API_KEY` 为空或失效 | 填好 env 文件后 `systemctl restart zhujian` |
| 启动很慢、内存不足 | 2核2G 套餐偏小 | 加 2G swap（见下）；或换 2核4G |

加 swap（2G 内存套餐建议做）：

```bash
fallocate -l 2G /swapfile && chmod 600 /swapfile
mkswap /swapfile && swapon /swapfile
echo '/swapfile none swap sw 0 0' >> /etc/fstab
```

## 十、安全与备份（公网开放后必做）

1. **数据库不要对公网开放**：当前 MySQL 只监听 `127.0.0.1`，不要改成 `0.0.0.0`
2. **密钥只放服务器**：`ARK_API_KEY` 在 `/etc/zhujian/zhujian.env`（权限 600），永远不要提交进 git
3. **限制 AI 调用额度**：公网开放后任何人点 AI 都会消耗你的 token，建议在火山方舟控制台设额度上限
4. **定期备份数据库**：

```bash
mkdir -p /backup
mysqldump -uroot --single-transaction zhujian | gzip > /backup/zhujian-$(date +%F).sql.gz
# 加到定时任务：每天凌晨 3 点
echo '0 3 * * * mysqldump -uroot --single-transaction zhujian | gzip > /backup/zhujian-$(date +\%F).sql.gz' | crontab -
```

5. **改掉演示账号密码**：`owner_demo / provider_demo / admin_demo` 都是 `123456`，上线前务必改

## 附：脚本做了什么（想手动操作时对照）

| 步骤 | 内容 |
|---|---|
| 1 | `apt-get install openjdk-17-jdk-headless` |
| 2 | `apt-get install mysql-server` → `systemctl enable --now mysql` |
| 3 | 建库 `zhujian`（utf8mb4）、建账号 `zhujian@127.0.0.1`、随机密码 |
| 4 | 建 `/opt/zhujian`、写 `/etc/zhujian/zhujian.env`（600 权限） |
| 5 | 写 `/etc/systemd/system/zhujian.service`（`-Xmx1024m`、崩溃自动重启、日志写 app.log） |
